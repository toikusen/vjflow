# 封測平台第一版（草稿，待與 Codex 討論）

日期：2026-10-27　狀態：草稿　分支：feat/lyric-editing

標示：**已驗證** = 讀程式或實測確認；**推論** = 未實測；**未測** = 沒有資料。

## 已定案（使用者決定）

- 邀請制封測：帳號由管理者開，不做公開註冊。
- 封測期間費用全由管理者支付；公開後再接金流。
- 音檔由使用者上傳（擁有權利的 mp3／wav），不提供 YouTube 下載。
- 三種方案：新導演無圖版、新導演有圖版、混合版（故事）。混合版不需人工審圖（手被標記時同姿勢重畫，見 cutout.mts redrawFlagged）。

## 使用者流程

1. 登入（受邀帳號）。
2. 新增歌曲：上傳音檔、貼歌詞、歌名／歌手／語言、選方案；翻譯歌詞選填（有翻譯才開上下雙語）。
3. 自動準備：人聲分離 + 歌詞對齊 → 現有對時間頁面 → 使用者確認。
4. 確認後排隊產出，顯示階段與進度（studio.mts 已有階段與進度）。
5. 完成：線上預覽、下載 1080p mp4。

## 管理頁

- 開／停帳號；每帳號用量上限（預設每月 5 首，可調）。
- 每首實際 API 花費、佇列、失敗工作一鍵重跑。

## 交片前自動檢查

- 全黑畫面：已完成（render.mts blackSpans）。
- 歌詞被遮（人物／道具）：渲染已有 "lyric covered" 量測，未成為擋關條件。
- 歌詞互相重疊：未做。
- 不合格 → 自動重跑一次 → 仍不合格通知管理者，不交片。

## 不在第一版

金流、公開註冊、團體 Logo、9:16、使用者寫意見修改。

## 已知成本／時間（已驗證，管理者 Mac 上）

- 無圖 ≈ $2.2–2.6、約 25 分；有圖 ≈ $3.5–4.2、約 25–30 分；混合 ≈ $10–11、約 45 分（另加手被標記時重畫，推論每首約 +$3）。
- 渲染用 Puppeteer + Chrome，3 個 worker 共用 GPU 時曾出現整段全黑。

## 未知

1. 自動檢查：歌詞被遮、歌詞重疊。
2. 準備流程改為接收上傳音檔（現在 prep-song.sh 從 YouTube 下載）。

## Codex 審查（2026-10-27）重點

已驗證缺口：
- 沒有「上傳 → 建立歌曲 → 準備 → 對時間」的伺服器串接；generator 只在瀏覽器分析（generator.store.ts:79–103）。
- song.mts 會優先採 LRCLIB 同步歌詞；使用者貼的歌詞要當權威來源須 `--no-lrclib`（song.mts:94–105）。
- Studio 沒有三方案路由；new-director.sh 一次規劃兩版；翻譯取自動產生的 `plan.lines.zh`，不是使用者輸入。
- 混合版：重要鏡頭（key shot）畫 5 次都失敗時保留並標「人工確認」（cutout.mts 約 645–650）。實績：第六感、Tokyo Drift 共 0 次。
- 自動檢查：黑畫面只抓 ≥3 秒；「歌詞被遮」只寫 console；沒有整首「重跑一次＋通知＋不交片」。
- Dashboard 無登入、無擁有者檢查；Studio 只限同首歌一次一個，沒有全站佇列與預算；進度在記憶體。
- 費用是部分估算，不能當帳本。
- 移植：ASR 用 Apple Silicon 專用 mlx-whisper；渲染是 Playwright + Chrome（不是 Puppeteer）。

建議架構（推論）：一台常駐主機，Angular 靜態站 + Node API + 獨立 worker；SQLite 存帳號、歌曲版本、工作、費用帳本；全站一次一首；每階段 checkpoint，失敗只重跑該階段；邀請帳號 + session + 逐資源權限；金鑰只在 worker；檔案放私有物件儲存、短效下載網址。

建議順序（推論）：雲端相容性實驗第一 → 持久化佇列、權限、預算預扣 → 上傳→準備→確認→產出→檢查→下載 → 自動檢查接成交片閘門。

## 使用者決定（2026-10-27）

1. 封測目的是測使用流程，每位測試者一兩首：用管理者自己的 Mac 當主機（網站經 tunnel 對外），工作排隊一次一首；雲端移植（換 mlx-whisper、無 GPU 渲染實測）留到公開前。
2. 用量上限用金額：每帳號一個總額上限，每首開始前預扣預估費用，重跑與失敗都計入；另設全站總上限。
3. 三種方案都開；混合版 key shot 失敗時通知管理者看那一張，不讓使用者等。

## 已實作（2026-10-27，未提交）

- `scripts/lyric-vj/beta/store.mts`：JSON 紀錄（帳號、歌曲、工作、費用），邀請 token 只存 hash；金額上限＝每帳號＋全站，開始前預扣（無圖 $4、有圖 $6、混合 $16、準備 $0.5），量到實際費用後以實際計。
- `beta/queue.mts`：全站一次一首；`##PHASE`／`##COST` 行回報進度與費用；重開機把執行中的工作放回佇列（各步驟會跳過已完成的輸出）；金鑰讀 `~/.config/vjflow/*.env`（互動式 zsh 在背景會卡住）。
- `beta/server.mts`：邀請連結登入（HttpOnly cookie）、上傳歌曲（歌詞＋音檔 80 MB 內）、對時間讀寫、選方案製作、下載、管理（邀請、額度、停用、新登入連結、重跑、放行）；也提供打包好的網頁。
- `beta/prep.sh`：上傳音檔 → mp3 → 人聲分離（`stems.sh`，與 prep-song.sh 共用）→ 用使用者的歌詞對齊（`--no-lrclib`）→ 錯字標記。
- `beta/make.sh`：三方案流程；混合版 key shot 失敗或歌詞被遮 >40% → 狀態「等管理者確認」（exit 10）。
- 網頁：`/my`（我的歌曲）、`/my/admin`（管理）、`/timing?beta=<id>`（沿用對時間頁）。
- `beta/start.sh`：打包網頁 + Cloudflare quick tunnel + `caffeinate -i` 跑伺服器。
- `beta/invite.mts`：在伺服器停止時建立第一個管理者。
