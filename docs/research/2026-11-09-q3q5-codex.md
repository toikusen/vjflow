# Codex Q3 (keyword scale) + Q5 (free signature moments) design (2026-11-09)

Both become candidates for planWorldEvents; the renderer never adds events on its own. Q3: edgeFitEmphasis = semantic big word with its ink box on the safe-area edge, the carrier runs off-frame, strokes never cut; targetSize = min(2.4×readingSize, frameCap, fitSize), ≥1.8× counts as a big word, 1.6–1.8 as ordinary scale contrast; one scale contrast per sung section with a seeded per-world choice among meaning candidates. Q5: meaning.json candidates only, hard floors (evidence, safe window, no collision), ranked 4·semantic + 3·worldFit + 2·musicalFit + readingSlack − repetition; miniMoment 15–30 % of frame, ≤2 per song, 30 s apart. Phase-1 work can start now in q3-scale-policy / q5-moment-policy worktrees as pure policy functions + tests + dry-run scripts.

建議：**Q3 做「每段一次尺度對比」，語意巨字是優先形式；Q5 改成「語意硬門檻＋音樂位置排序」。兩者都交由 `planWorldEvents()` 核准，渲染端不得自行補事件。** 以下是設計提案與驗收門檻，尚未實測；本次未修改檔案。

1. **Q3：`edgeFitEmphasis` 的規則**
   - 候選來自既有 `meaning.keys` 的完整詞組與對應句；不得沿用 `blowOf()` 的句尾詞後備來冒充語意重點。1–4 字只是優先尺寸，混排與長詞依實際字形量測，不直接排除。
   - 段落第一句沒有優先特權；`peak` 是排程器核准的尺度座位，不是語意來源。先選有意義且放得下的候選，再配置座位。
   - 定義 `readingSize` 為該句在同世界普通座位的實際閱讀字級；`fitSize` 為完整詞組、其餘歌詞與安全距離共同容許的最大字級。
   - 建議 `targetSize = min(2.4 * readingSize, frameCap, fitSize)`；`frameCap` 限巨字墨框高度 ≤ 畫高 44%、寬度 ≤ 安全區寬度 86%。正式巨字須達 `targetSize / readingSize >= 1.8`；1.6–1.8 只算一般尺度對比。
   - 其餘歌詞維持原閱讀字級與世界下限；不縮小配角、不壓窄字形來湊倍率。放不下先換合法座位／斷行，再換候選。
   - 巨字的**墨框**貼齊世界允許的安全區邊界；安全區取畫框、固定版心、`clear` 區域的交集。載體沿同側延伸出畫，字與字形副本都不能出血。
   - 固定頁面保留原 `carrierId`、版心與承載關係；不能照現行部分 `blow` 路徑把物件拿掉，再讓字浮到背景上。
   - 全演唱期間檢查實際筆畫、字距、讀序、直接底色對比 ≥4.5:1，以及鏡頭、傾斜、描邊、位移後的完整邊界。

2. **Q3 與 Q2／Q1 是同一個主事件**
   - `edgeFitEmphasis` 作為 `layout-seat` 候選的排版參數；核准後共用一個 `eventId`、一個時窗、一次計數。
   - 優先在開唱前完成巨字構圖，唱詞期間保持；若句內改變，必須通過 Q1 可靠詞界及前後各 0.35 秒穩定閱讀規則。
   - 同次尺度轉換不得再排獨立 Q2 `line-grow`，也不把兩個倍率相乘。一般 Q2 小幅 grow 未達 1.6×，不能抵 Q3 配額。
   - 沿用 Q2 round 3 的 `growFits`／hold-room 幾何限制；渲染以 `growTo` 同等的實際邊界再驗一次。預估通過、實畫不足倍率時標 `unrealized`，改候選，不能偷偷算成功。
   - 已固定的 Q2／Q4 時窗照契約保護；Q3 換合法候選，不擠掉它們。跨句 seam、動作與換光間距仍是 0.65／0.10／0.55 秒。

3. **兩種世界口味與段落覆蓋**
   
   | 世界能力提案 | 巨字與載體 | 選句偏好 |
   |---|---|---|
   | `riso.edgeFit` | 完整大字靠紙張外緣；同一紙面／色版出畫，副版不得侵入主字保護區 | 語意候選中，偏好較短詞、較多留白、可持續閱讀的句子 |
   | `screentone.edgeFit` | 完整大字靠漫畫格內緣；頁面與格框出畫，網點及線條留在閱讀區外 | 語意候選中，偏好可建立主次格、讀序清楚的句子 |

   - 能力放在 `world-shared.ts`：宣告 `edges`、`carrierRole`、`sizeRange`、`curve`、`candidateWeights`；沒有歌詞正規表示式，也不由世界名稱猜語意。
   - 大平塗遵守新 design bar：有核准依據可直接使用；否則驗證 `paper`／`plate`／`ground` 角色，不強制加紙紋、陰影或雜訊。
   - 現行程式按 `meaning.parts` 用 `blownParts` 發名額，量測按 `song.sections`；`namedLater()` 又偏向同一組命名句。另有 1.4 秒、2–4 字、詞長占比、呼喊、`piece` 與固定載體限制。
   - **推論：**上述分段不一致、共同選句與後續排版拒絕共同造成覆蓋不足；沒有逐段拒絕追蹤，不能斷言缺的七段各是哪個原因。
   - 改用與量測相同的 `sectionId`；跨界句固定依起唱歸屬，不能重複抵兩段。每個有唱詞段落保留一個尺度對比名額。
   - 語意候選先依世界能力評分，再在近似品質候選間用 `hash(songId, sectionId, worldId, seed)` 選擇；避免固定取第一個，也不為差異故意選差句。
   - 無合法語意巨字時，改用完整句子的 `sectionScale` 座位，達普通閱讀字級 ≥1.6×；這是段落層級排版，不宣稱找到關鍵詞。
   - 若整句也放不下，保留未達標紀錄。全段覆蓋是產品目標，不能靠裁字或縮減分母保證；`ochi` 可用安靜的大字留白，尺度大不等於動作猛烈。

4. **Q3 驗收腳本**
   - 新增提案 `measure-scale-coverage.mts`：固定歌曲、45 個 `OFFERED_STYLES`、seed 0，另跑多種子；逐段輸出候選、語意來源、選句分數、事件 ID、預估／實畫倍率與拒絕原因。
   - 舊兩首基線的分母仍為 17 段；每世界目標 `renderedScaleSections === sungSections`。另列 `edgeFitSections`，不得把整句尺度後備算成語意巨字。
   - 具兩個以上共同合法語意候選的段落，跨世界至少出現兩種選句；單候選段不要求假差異。同輸入重跑結果必須一致。
   - 所有演唱幀驗裁字、碰撞、遮擋、字級下限與對比；核准事件與渲染事件一對一，同一尺度轉換沒有重複 Q2／Q1 ID。
   - 影片另驗縮圖主次、原尺寸閱讀、200% 邊緣與正式幀率連續播放；計畫有 `blow` 不代表畫面成功。

5. **Q5：硬條件、排序與 `miniMoment`**
   - 硬條件：只能從現有 `meaning.json` 的 `moments` 取得候選；必須有合法 cue、完整證據詞、可追溯 `why`、可靠演唱時間、可用世界能力與安全閱讀窗口。
   - 保留 `checkMoments()` 的語意／完整詞／否定／呼喊鄰近檢查；既有詞表只能驗證已提出的候選，不能掃歌詞產生時刻。
   - 必須與已核准 Q1／Q2／Q4／Q3 事件無衝突；全程不隱藏正在唱的筆畫。效果退場、復原也包含在占用時窗內。
   - 候選獨立驗證後才排序；不能先讓現行 `checkMoments()` 依輸入順序套三個上限與間距，提前丟掉較佳候選。
   - 建議分數：`4 * semanticSpecificity + 3 * worldFit + 2 * musicalFit + readingSlack - repetitionPenalty`；各項先正規化至 0–1，分數構成寫入報表。
   - `semanticSpecificity` 衡量既有證據與動作的直接對應，不捏造模型信心；`musicalFit` 以副歌重拍最高、段落轉折其次、其他語意起音再次。副歌／重拍缺席不淘汰。
   - 語意動作固定在原 `at`；只可把預備動作接到拍點，不能移到別的詞。`ochi` 偏向留存、收束形式，不自動製造爆點。
   
   | 呈現家族 | `miniMoment` 定義 |
   |---|---|
   | 頁面 | 既有紙面／色版局部開合、分離或留存，表達原候選的語意；閱讀面完整 |
   | 場景 | 已有且有語意依據的物件局部動作或關係改變；不臨時新增裝飾道具 |
   | 純字體 | 完整語意詞組建立一次留存、呼應或間距關係；不靠普通換墨／放大冒充簽名 |

   - `miniMoment` 的實際作用區占畫面 15–30%，主動作建議 0.35–0.6 秒；不是把全螢幕效果縮小貼角落。無合理映射就拒絕。
   - 大型與 mini 合計每首 ≤2，至少相隔既有 `MOMENTS_APART = 30` 秒，同段最多一個；先求一個成立，再選不同語意／形式的第二個。無證據允許 0。

6. **Q5 進入 `planWorldEvents()` 的方式**
   - 選擇**由排程器排程的候選輸入**，不仿 Q4 一開始就 `fixed: true`；否則兩個稀有時刻可能反過來破壞既定閱讀與交接。
   - 候選帶 `id`、`at`、`from`、`to`、`cueIds`、`meaningRef`、`variant`、`score`、`changesLight`、保護區及渲染能力。
   - 先保護固定 Q2／Q4，再仲裁 Q3／Q5 與可選 Q1；核准後才成為受保護事件。選不到就試下一候選，不能任意移動語意起音。
   - `freeMoments()` 最終只轉譯核准結果；mini 預設保留正常歌詞 renderer，不直接套大型時刻的整句接管與 `ownCues` 行為。

7. **Q5 驗收**
   - 提案 `measure-free-moments.mts` 跑固定五首完整歌曲 ×45 世界：每列 `0 <= realizedMoments <= 2`；定義「多數歌曲」為 **至少三首各自在 ≥36／45 世界實現 ≥1 個時刻**。
   - 這是待驗收目標，並非已有證據可達成；若現有語意候選不足，報告 `noMeaningCandidate`，不得補關鍵字觸發或移除歌曲。
   - 固定既有 `meaning.json` 雜湊；攔截並計數所有對外 API 呼叫，要求 0。另測無金鑰、無語意快取：API 0、時刻 0，正常影片仍成立。
   - 加入「歌詞含觸發字但沒有 moment」「否定語意」「呼喊衝突」「非副歌合法候選」測試；每個實現事件須能回溯至原始候選。
   - 視覺驗收比較同 seed 開／關版本：語意動作可辨認、作用區達標、載體完整、閱讀無損；普通 beat 或只有計畫紀錄不得計數。
   - 新 23 世界文字完全靜止比例 0.79、舊世界 0.12 是另列診斷；每首最多兩個時刻不足以解決整首靜止問題，不能拿 Q5 宣稱補完 Q2。

8. **順序與 worktree 計畫**
   - 順序：Q2 round 3 合併 → Q1 phase 2 接線及重跑基線 → Q3 排程／渲染 → Q5 排序接線／mini 渲染。
   - 現在可在 `vjflow.worktrees/q3-scale-policy`、`vjflow.worktrees/q5-moment-policy`，分別以 `feat/q3-scale-policy`、`feat/q5-moment-policy` 做純候選函式、能力型別草案、fixture、單元測試與 dry-run 驗收腳本。
   - 此階段不碰題列五個共享檔案；`world-shared.ts` 的能力值先存獨立草案模組，待 Q1 的 `compositions` 契約落定再由單一整合變更接入。
   - Q3 現在先查清每段漏選原因；Q5 現在先列五首候選各道閘門的淘汰數。兩者都可驗證政策，不能宣稱已改善影片。
   - Q2／Q1 落定後，各 worktree rebase 到共同基底，再依序接入；每個功能連同單元測試交付，最後以同版引擎跑完整矩陣與影片驗收。
