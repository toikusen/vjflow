## 1. 結論

新手在「額度夠、第一次概念就接受、工作順利」時有機會自己走完 上傳 → 時間 → 概念 → 接受 → 影片 → 回報；但不是可靠的自助流程。四個最可能卡住的地方：

1. **歌詞時間編輯器**：不知道紅色「必須修正」要不要改（其實是「系統聽起來可疑，請你聽一下」）、不知道怎麼檢查、手機沒有教學也不能拖波形。
2. **所有死路都寫「請聯絡管理者」，產品內沒有聯絡方式**；「儲值」是假門，額度不足的人會先點它。
3. **等待預期混亂**：準備時間兩套數字、排隊預估不含等待、「約剩 N 分鐘」超時後停住、「管理者確認後就能下載」沒期限。
4. **付費前資訊不足**：3 次概念上限、調整後不能回選、修正的實際範圍（單點＝2 秒＋整個鏡頭；「圖片不搭」的修正＝拿掉圖）、三個方案長什麼樣。
