## 步驟 2：可信的候選與量測

**座位幾何**：`render/seat-geometry.ts` `laidSeat(text, set)` 用 set 自己的 `blockOf()`（plan 的粗略字寬，與 `growFits` 同一把尺）算出字實際排下的框（含 shear、分拆的兩部分）、字級、直橫、以及該頁大圖形的區域。`seatIn(world, set, text)` 帶上這些；`fromJob()`、`currentEvents()` 都用每句自己的字算。

**`seatsDiffer()`**：不再比名目框或 set 名稱。同一句字（句內）比框中心與字級（≥ 0.08 或字級差 1.25 倍）；兩句之間比「各錨點（左／中／右、上／中／下）最小的位移」，所以同一座位換長句不算移動，字級要差 1.9 倍才算（字級跟句長走，與影格檢查同一門檻）。不同載體、直橫互換仍一律算不同。同一 set id 一律相同。

**影格檢查**（`scripts/lyric-vj/frame-change.mts`，頁面由 `frame-page.mts` 共用閱讀閘門的 render page）：
- 穩定幀改在閱讀時間內取（`stableTimes()`，用引擎的 readable 時窗）：換句時取上一句還在讀、尚未退場的幀，換座後取入場結束後的幀。phase 2 的取法常拍到上一句的退場動畫。
- 量：字框的錨點位移（句內用中心）、字級（行或欄的粗細中位數，不是墨量）、尺度關係（字內最大／最小行比，抓「放大一個字」）、直橫、字底下東西的**邊緣**變化（只換底色時邊緣不變；新頁、新面板、載體輪廓會變）、字在載體上的相對位置。

## 步驟 3：同頁座位

`world-shared.ts` `compositions` 新增 `pageSeats`（以 set 為 key 的同頁座位）與 `minType`（最小字級）；三個世界的 `layout-seat` 允許 `in-line`。同頁座位是獨立的 set（`world-b5-sets.ts`、`world-b4-sets.ts`），由原 set 複製墨色、表面、shear、頁面的 `clear`，拿掉分拆部分，`world-layout.ts` 照真實幾何排（不需改 renderer：它本來就逐 pose 讀 `SET_SPECS`，頁面圖形本來就繞著字的 cells 畫）。`pageOf()` 讓同頁座位回到原頁，所以 `seatIn()` 給同一個 `carrierId`，排程器的句內池（同載體）自然包含它，而換到別頁的 set 仍只能在換句時。

|---|---|---|---:|
| notebook | spiral、spiral-r、dotted、dotted-r | `+margin`：主欄下方、貼紅色邊線（dotted 為右下、避開書籤帶），小一號；頁面的圈、底線照樣繞著字畫 | 96 px |

## 決定（文件沒寫到的地方，選保守做法）

1. **notebook 的「頁邊」解釋為主欄下方、貼紅色邊線的閱讀區**，不是紅線左邊那條窄邊：那條只有約 0.08 畫面寬，放不下 ≥ 96 px 的字，硬放就違反「頁邊仍需足夠字級」。dotted 頁放右下，避開書籤帶。
2. **art-deco 只在 marquee／marquee-low 兩頁加副版心**：那兩頁有固定的階梯雙框，「同框」成立；arch、plaque、pillars 的框是繞著字長出來的，換位置等於整個框跟著移動，不算同框，所以不加。
3. **`protect`（頁面圖形不可進入）只檢查排程器新增的同頁座位**，composer 原本的 set 不檢查：例如 blueprint part 頁的剖面圖在字太長時本來就會讓開（頁面自己處理），對原 set 強制檢查會改掉核准的行為。
4. **blueprint 只在 part、construct（含鏡像）加細部說明列**；notes 頁的「1. 2.」編號依行數畫，lettering 是一字一格，加座位會破壞它們的構圖。
5. **同頁座位都沒有分拆（small tail）**，行數 1–2（blueprint 1 行）；放不下就不提供，不縮到最小字級以下。
6. **影格檢查門檻取保守側**（寧可少算 realized）。
7. **`seatsDiffer` 兩句之間字級要差 1.9 倍才算**，與影格檢查同一門檻：字級跟句長走，1.7 倍的差在 popart 是同一個對話框。
8. `MOOD_PACE` 連續上限、「句內不換 carrierId」、0.55／0.65／0.10／0.35 全部不動；`keep` 照舊是正常結果。
