# 歌詞 VJ：情緒曲線與段落爆點

日期：2026-10-03　狀態：第一版已實作（`src/app/lyric-vj/moments.ts`）

## 問題

整首豐富版與純圖片版的畫面已經可用，但從頭到尾強度一樣：進副歌、落ちサビ、最後副歌沒有起伏與爆點。

## 資料庫依據（vjanalytics，50 支）

- 145 個「進入副歌」的段落交界，50 支全部有特別處理。關鍵字粗略統計：光束／光芒／粒子 36%、色調轉換 34%、鏡頭推近衝進 14%、白閃 13%、大字砸下 12%、遮罩擦除 11%、速度變化 10%、碎裂 9%、震動／故障 7%、黑場停頓 5%。
- 最後副歌／落ちサビ 24 處：典型是先收（變暗、留白、短暫暗場）再爆發。
- 導歌末醞釀：44 支有 61 個模式，最後 1–1.5 秒加速切換、背景節奏閃切蓄力。

## 設計

兩層資料由導演寫進企劃，引擎逐格換算成特效量（`fxAt`，純函式、可測）：

1. **情緒曲線 `arc`**：每段強度 0–3。影響背景亮度與飽和度、光暈、光粒子亮度。段落變化在 1.2 秒內平滑過渡；遇到 drop／finale 則在 0.15 秒內跳升。
2. **爆點 `moments`**（吸附到強拍或句首 ±0.35 秒）：

| 種類 | 時間 | 效果 |
|---|---|---|
| build | `at` 前 1–8 秒 | 推鏡 8%、背景漸亮 +25%、光暈、暗角收緊、粒子加速；到點後約 1 秒放開 |
| drop | `at` | 地平線光束放射（約 3 秒消散）、震波環 1.4 秒、鏡頭衝進 9% 約 1.5 秒回彈、背景曝光 +50%、粒子被吹散 |
| break | `at` 起 2–30 秒 | 背景降飽和 60%、變暗 30%、粒子減速到 30% |
| hold | `at` 前 0.3–1.2 秒 | 背景壓黑到 95%（星光粒子與文字保留） |
| finale | `at` | drop 的 1.5 倍 |

## 強度原則

第一版（鏡頭 ≤5.5%、曝光 ≤+42%、約 0.5 秒）使用者看了覺得「太快太小、沒感覺」，第二版約 2 倍強、2–3 倍長：drop 曝光 +50%（finale +75%）、衝進 9%（finale 13.5%）約 1.5 秒回彈、光束約 3 秒消散、震波 1.4 秒、build 推鏡 8%。上限：鏡頭 ≤14%、背景曝光 ≤+80%。

- 不往白色混（白色疊在深色背景上會變成灰霧）：只做曝光與加光。
- 亮度、飽和度只作用在背景，歌詞永遠不變灰。
- strength 0.5–1.5，導演規則建議 0.8–1.3。
- 有 drop／finale 的鏡頭略過舊的 flash 轉場，避免疊加。
